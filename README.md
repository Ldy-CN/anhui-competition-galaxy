# 安徽省大学生竞赛一览 · 3D 竞赛星系

> 面向全体本科生的学科竞赛发现与推荐工具。把安徽省大学生可以参加的 61 项竞赛做成一个可交互的 3D 星系，并根据**你的专业、学校、年级、技能与兴趣**计算专属推荐分。

**🔗 在线访问**：开启 GitHub Pages 后即为仓库首页（见下方部署说明）

---

## ✨ 特性

- **🌌 3D 竞赛星系**（Three.js）：61 张竞赛卡片按六大类别分扇区漂浮，推荐分越高的竞赛越靠近星系核心。支持拖拽旋转、滚轮缩放；近处卡片自动变淡透出后面的卡片，点击穿透直达详情。
- **🎯 个性化推荐引擎**：填写「我的画像」（专业类别 / 学校层次 / 年级 / 掌握的技能 / 感兴趣的方向 / 主要目的），六维评分模型实时为全部 61 项竞赛重新打分，星系布局、榜单、详情同步重排。画像保存在本机浏览器（localStorage），不会上传。
- **🛤 赛道级细分推荐**：多赛道大赛（西门子杯 11 个赛项、安徽省机器人大赛 6 大赛道、智能汽车 3 类赛道、中国国际大学生创新大赛 5 大赛道等）下钻到**具体赛道**——按你的画像计算每条赛道的适配度并排序，标注「⭐ 强烈对口 / ✓ 可以参与 / △ 谨慎选择 / ⛔ 不适用」，并给出「与你最匹配的赛道」结论；赛道所需技能逐项对照你的掌握情况。
- **📊 推荐分维度分解**：每项竞赛的详情页展示得分构成——专业匹配(35) / 技能储备(25) / 年级适配(10) / 可达性(15) / 兴趣方向(10) / 目的加成(5)，为什么推荐一目了然。
- **📅 报名状态与倒计时**：按你打开页面的日期实时计算每个报名窗口的状态（报名中 · 剩 X 天 / 约X天后开启 / 窗口未开），跨年窗口自动处理；左下角横幅汇总「今天就能报名」的竞赛。
- **📖 赛事简介**：每项竞赛内置 2-4 句官方信息摘要（主办单位、赛项设置、赛制、奖项规则），无需跳转官网即可快速判断；需要细节时再一键前往官网。
- **🔍 多维筛选**：关键词搜索、六大类别开关、推荐分区间双滑块、「报名临近优先」一键排序、榜单视图与 3D 视图自由切换。
- **📴 单文件离线可用**：Three.js 以 base64 内嵌于 HTML，下载后断网也能打开（适配校园网断网时段）。

## 🎓 评分模型

```
推荐分 = 专业匹配(35) + 技能储备(25) + 年级适配(10) + 可达性(15) + 兴趣方向(10) + 目的加成(5) + 赛道契合(6)，上限 100
```

- **专业匹配**：12 个专业大类与六大竞赛类别（智能制造 / 机械建模 / 机器人电子 / 双创商业 / 数理基础 / 人文艺设）的映射权重
- **技能储备**：每项竞赛标注所需技能（三维建模、单片机、编程、电路、数据分析、写作、演讲、设计、英语），按命中率给分
- **可达性**：竞赛竞争强度 × 你的学校层次（竞争越温和、与学校层次越匹配分越高）
- **目的加成**：考研保研 / 综测刷分 / 就业技能 / 兴趣探索，与赛事定位契合时加分
- 仅限特定群体的赛事（师范类、医学药学类、职业院校类）对不匹配画像自动标注「不适用」

## ⚠️ AI 生成内容声明

1. **内容来源**：本页面全部竞赛信息（含赛事简介、赛道说明、报名窗口、组队要求与技能需求标注等）由 AI 根据各赛事官方网站公开发布的通知、规程与介绍**整理生成**，数据检索日期为 **2026 年 10 月 23 日**。
2. **推荐分仅供参考**：推荐分与适配标注由页面内置的评分模型基于用户填写的画像自动计算，仅为参考建议，不构成任何形式的官方认定、评奖承诺或升学依据。
3. **以官网为准**：竞赛的报名时间、赛制、赛道设置、奖项规则等信息**以各赛事官方网站发布的最新通知为准**；本页信息可能滞后于官网更新，或存在整理疏漏。
4. **报名前请核实**：报名前务必前往对应官网（详情页已提供链接或渠道说明）核对原始通知，并向本校教务处 / 学院确认报名渠道与综测认定政策。
5. **非官方声明**：本页面为非官方的个人学习参考工具，与安徽省教育厅及各赛事主办方无任何隶属或合作关系。

## 🚀 使用方法

**方式一（推荐）**：开启 GitHub Pages 后直接访问在线链接。

**方式二（离线）**：下载 `index.html`，双击用任意现代浏览器（Edge / Chrome / 夸克等）打开即可，全程无需联网。

## 🛠 技术栈

- [Three.js r128](https://threejs.org/)（base64 内嵌，UMD 加载，兼容较旧的浏览器内核）
- 原生 JavaScript / CSS，**零依赖、零构建、单文件**（约 880 KB）
- 兼容性：不使用 ES2020+ 语法与 importmap，Chrome 60 级以上内核均可运行
