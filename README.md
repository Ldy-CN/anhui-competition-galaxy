# 安徽省大学生竞赛一览 · 3D 竞赛星系

> 面向全体本科生的学科竞赛发现与推荐工具。把安徽省大学生可以参加的 83 项竞赛做成一个可交互的 3D 星系，并根据**你的专业、学校、年级、技能与兴趣**计算专属推荐分。

**🔗 在线访问**：开启 GitHub Pages 后即为仓库首页（见下方部署说明）

---

## ✨ 特性

- **🌌 3D 竞赛星系**（Three.js）：83 张竞赛卡片按六大类别分扇区漂浮，推荐分越高的竞赛越靠近星系核心。支持拖拽旋转、滚轮缩放；近处卡片自动变淡透出后面的卡片，点击穿透直达详情。
- **🎯 个性化推荐引擎**：填写「我的画像」（专业类别 / 学校层次 / 年级 / 掌握的技能 / 感兴趣的方向 / 主要目的），六维评分模型实时为全部 83 项竞赛重新打分，星系布局、榜单、详情同步重排。画像保存在本机浏览器（localStorage），不会上传。
- **🛤 赛道级细分推荐**：多赛道大赛（西门子杯 11 个赛项、安徽省机器人大赛 6 大赛道、智能汽车 3 类赛道、中国国际大学生创新大赛 5 大赛道等）下钻到**具体赛道**——按你的画像计算每条赛道的适配度并排序，标注「⭐ 强烈对口 / ✓ 可以参与 / △ 谨慎选择 / ⛔ 不适用」，并给出「与你最匹配的赛道」结论；赛道所需技能逐项对照你的掌握情况。
- **📊 推荐分维度分解**：每项竞赛的详情页展示得分构成——专业匹配(35) / 技能储备(25) / 年级适配(10) / 可达性(15) / 兴趣方向(10) / 目的加成(5)，为什么推荐一目了然。
- **📅 报名状态与倒计时**：按你打开页面的日期实时计算每个报名窗口的状态（报名中 · 剩 X 天 / 约X天后开启 / 窗口未开），跨年窗口自动处理；左下角横幅汇总「今天就能报名」的竞赛。
- **📖 赛事简介**：每项竞赛内置 2-4 句官方信息摘要（主办单位、赛项设置、赛制、奖项规则），无需跳转官网即可快速判断；需要细节时再一键前往官网。
- **🔍 多维筛选**：关键词搜索、六大类别开关、推荐分区间双滑块、「报名临近优先」一键排序、榜单视图与 3D 视图自由切换。
- **📴 离线可用**：`index.html` + `three.min.js` + `orbit.min.js` 三文件同目录，断网也能打开（适配校园网断网时段）。

## 🎓 评分模型

```
推荐分 = 专业匹配(35) + 技能储备(25) + 年级适配(10) + 可达性(15) + 兴趣方向(10) + 目的加成(5) + 赛道契合(6)，上限 100
```

- **专业匹配**：12 个专业大类与六大竞赛类别（智能制造 / 机械建模 / 机器人电子 / 双创商业 / 数理基础 / 人文艺设）的映射权重
- **技能储备**：每项竞赛标注所需技能（三维建模、单片机、编程、电路、数据分析、写作、演讲、设计、英语），按命中率给分
- **可达性**：竞赛竞争强度 × 你的学校层次（竞争越温和、与学校层次越匹配分越高）
- **目的加成**：考研保研 / 综测刷分 / 就业技能 / 兴趣探索，与赛事定位契合时加分
- 仅限特定群体的赛事（师范类、医学药学类、职业院校类）对不匹配画像自动标注「不适用」

## 🔄 数据更新指南

数据以快照形式维护在 `index.html` 中。更新一份竞赛信息只需三步：

1. **获取依据**：从赛事官网获取最新通知（这是唯一的信息来源）
2. **修改数据**：编辑 `index.html` 中 `DATA` 数组对应条目，字段说明如下
3. **提交推送**：`git commit` + `git push`，GitHub Pages 自动重新部署

<details>
<summary>DATA 字段说明（点击展开）</summary>

| 字段 | 说明 |
|---|---|
| `name` | 竞赛全名（唯一键，META/TRACKS/INTROS 均按此匹配） |
| `cat` | 类别：`smart` 智能制造 / `mech` 机械建模 / `elec` 电子机器人 / `innov` 双创商业 / `basic` 数理基础 / `arts` 人文艺设 |
| `lvl` | 级别描述（如 `国家级A类`） |
| `sS` / `sE` | 报名窗口 `"MM-DD"`（自动处理跨年，如 `'10-08'~'04-26'`） |
| `when` | 比赛时间描述 |
| `site` / `url` | 官网名称 / 官网链接（无固定官网则 `url` 留空） |
| `team` | 组队要求 |
| `score` | 初始参考分（实际展示分由画像引擎实时计算覆盖） |
| `why` | 推荐理由（支持 `<b>` 标签，会按画像个性化生成） |
| `note` | 亮点标签数组 |
| `intro` | 赛事简介（依据官网通知整理） |
| `skills` | 所需技能标签数组：`modeling` / `mcu` / `coding` / `circuit` / `data` / `writing` / `speech` / `design` / `english` |
| `bestYear` | 最佳参赛年级数组（如 `[2,3]`） |
| `intensity` | 竞争强度 1-5（用于可达性计算） |

| `restrict` | 群体限定：`teacher` 师范类 / `pharmacy` 医学药学类 / `vocational` 职业院校（其他群体自动标「不适用」） |
| `tracks` | 赛道数组（可选）：`{ n: 赛道名, s: 所需技能, note: 说明, vet: true 则其他群体不可报 }` |

同时请检查 `META`、`TRACKS`、`INTROS` 三个表中对应条目是否需要同步更新。

## 🤖 自动官网监控（GitHub Actions）

仓库内置定时任务（每天北京时间 09:00，见 `.github/workflows/check-updates.yml`），自动访问 14 个赛事官网的通知页并检测页面变化：

- **只侦测变化，不自动改数据**——有变化时自动开一个 `monitor` 标签的 Issue 提醒人工核实（防轰炸：同时最多 3 个未关闭监控 Issue）
- 页面底部声明条会显示「官网监控：最近自动检查 X月X日 · 各来源无变化 / N 个来源曾检测到官网更新」
- 监控源清单：`monitor/sources.json`（可自行增删）；状态文件：`monitor/monitor-state.json`
- 修改更新频率：编辑 workflow 中 `cron` 表达式（`0 1 * * *` = 每天北京时间 09:00）

## 🚀 使用方法

**方式一（推荐）**：开启 GitHub Pages 后直接访问在线链接。

**方式二（离线）**：下载 `index.html`、`three.min.js`、`orbit.min.js` 三个文件放同一目录，双击 `index.html` 即可，无需联网。（若仅下载 `index.html` 单个文件，页面联网时会自动从公共 CDN 加载 3D 引擎，同样可用）

## ⚡ 加载性能

- 在线版首屏 **191 KB**（数据 + 界面秒级就绪，可先浏览榜单）
- Three.js 引擎（614 KB）拆分为独立文件，与页面**并行加载**，站点本地优先、公共 CDN（npmmirror / jsDelivr）自动回退
- 实测 3D 就绪 ≈ 0.5s（本地缓存/快网络）～ 数秒（首次访问），较单文件时代的整页等待大幅缩短

## 🛠 技术栈

- [Three.js r128](https://threejs.org/)（UMD 加载，兼容较旧的浏览器内核；在线版独立文件 + 多源回退，离线包随文件分发）
- 原生 JavaScript / CSS，**零依赖、零构建**
- 兼容性：不使用 ES2020+ 语法与 importmap，Chrome 60 级以上内核均可运行
